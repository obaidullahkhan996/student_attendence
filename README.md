# Student Attendance Tracker

## About the Project
This is a simple Student Attendance Tracker built using Python. I created this project to practice Python fundamentals and improve my problem-solving skills.

The program allows users to manage students and track their attendance through a menu-driven system.

## Features
- Add new students
- View all students and their attendance status
- Mark students as present
- Display attendance summary
- Count total, present, and absent students
- Exit the program

## Technologies Used
- Python 3
- Lists
- Dictionaries
- While Loops
- For Loops
- If/Else Conditions
- String Methods

## How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code or your terminal.
3. Run the following command:

```bash
python main.py
```
